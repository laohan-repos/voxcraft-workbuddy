## 请求结构

```
POST https://api.minimaxi.com/v1/t2a_v2
Authorization: Bearer <API_KEY>
Content-Type: application/json
```

```json
{
  "model": "speech-2.6-hd",
  "text": "要合成的文本",
  "stream": false,
  "voice_setting": {
    "voice_id": "female-yujie",
    "speed": 1.0,
    "vol": 1.0,
    "pitch": 0,
    "emotion": "happy"
  },
  "audio_setting": {
    "sample_rate": 32000,
    "bitrate": 128000,
    "format": "mp3",
    "channel": 1
  },
  "output_format": "hex"
}
```

- `emotion` 可选：`happy` / `sad` / `angry` / `fearful` / `disgusted` /
  `surprised` / `neutral`，留空则不指定。
- `speed` 0.5~2.0，`pitch` -12~12，`vol` 0.1~10。
- `output_format: "hex"` 时音频在响应体 `data.audio`，为 hex 字符串，
  需 `binascii.unhexlify()` 解码后写文件。

## 调色拉取音色表

```
POST https://api.minimaxi.com/v1/get_voice
Authorization: Bearer <API_KEY>

{"voice_type": "system"}
```

返回 `system_voice` 数组，每项含 `voice_id` / `voice_name`。

## 响应结构

```json
{
  "data": { "audio": "<hex>", "status": 2 },
  "extra_info": {
    "audio_length": 14256,
    "audio_format": "mp3",
    "audio_sample_rate": 32000,
    "audio_size": 229812
  },
  "trace_id": "071e11f659ecda743dbf5b448a4a2fab",
  "base_resp": { "status_code": 0, "status_msg": "success" }
}
```

`base_resp.status_code == 0` 表示成功，`extra_info.audio_length` 为毫秒。

## 模型对比（实测）

| model | 定位 | 短文本耗时 |
|---|---|---|
| `speech-2.6-hd` | 最新 HD，音质最佳 | ~1.0s |
| `speech-2.6-turbo` | 最新 Turbo，快 | ~1.1s |
| `speech-02-hd` | 上一代 HD | ~1.7s |
| `speech-02-turbo` | 上一代 Turbo | ~1.2s |
| `speech-01-turbo` | 初代 Turbo | ~1.0s |

长短文本实测：360 字符中文 → 78 秒音频，耗时 2.55s。

## 错误码

| status_code | 含义 | 处理 |
|---|---|---|
| 1004 | 鉴权失败 / Key 无效 | 检查 Key 与 `Bearer ` 前缀 |
| 1008 | 余额不足 | 充值 |
| 1026 | 内容安全审核未通过 | 调整文本 |
| 2013 | 参数不合法 | 检查 model / voice_setting |
| 2054 | voice id not exist | 音色 ID 不存在，核对拼写 |
| — | rate limit exceeded(RPM) | 触发限流，降并发 |

## 限流

高并发（实测 8 并发）会返回 `rate limit exceeded(RPM)`。
建议**串行调用**或 ≤2 并发，批量时请求间加间隔。
